# -LNG208 CW-
Analysis Script, Stimuli and Data for Prediction in Chinese-English Bilinguals: The relationship between prediction and working memory capacity.

This is my first behavioral experiment (collaborate with Ms Minjie Liu) in LNG208 Psycholinguistics (Supervised by Dr Dawei Wei).

Here, we found an interesting three-way interaction using self-paced reading paradigm: L2proficiency * Predictability * WMC(OSPAN)!

A hypothesis: WMC alone is not the modulator in L2 prediction, it serves as the modulator of modulator, which echoes with the opinion "WM effiency matters more than absolute capacity in L2 processing."

LMEM (with by-participant and by-item intercepts), simple slope, interaction analysis were employed.

Results should be interpreted with cautious given the limited sample size and statistical power:)
